# Everly

Exam Project 1 - Noroff

Everly is an online store I built for my first exam project at Noroff.

The website is built with HTML, CSS and JavaScript, using the Noroff API to display products.

I wanted to create a simple and welcoming online store where users can browse products, create an account, add items to their cart, and go through checkout. I also wanted the design to feel clean and easy to use, both on desktop and mobile.

## Features

- Responsive design for desktop and mobile
- Products fetched from the Noroff API
- Product carousel and product details
- Product search and category filtering
- User registration and login
- Shopping cart with quantity controls
- Checkout and order confirmation
- Mini-cart for quick access to cart items

## Technologies used

- HTML5
- CSS3
- JavaScript
- Noroff API
- Figma
- GitHub and GitHub Pages
